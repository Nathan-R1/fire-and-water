# Levels

The game plays the files `NN-name.json` in number order. When both characters stand in their doors for half a second, the level is complete and the next one loads. After the last level (64) it goes back to level 1. Players can also jump to any level by tapping the level name in the top bar.

To check every level, run `npm run levels`. It also runs as part of `npm test`. The checker approximates movement on the tile grid. It catches exits, gems and switches that can't be reached, but it **does not prove a level is solvable**, so you still need to playtest. To jump straight to a level, open `/?level=N` (this only works in a new room) or use the level picker. To see a level as text with its pulleys, plates, levers and gates drawn in, run `node tools/showlevel.js 42`.

## Format

Each level is 40×23 tiles of 24px. The `rows` field is a picture of the level in characters:

| Char | Meaning |
|---|---|
| `#` | Rock |
| `.` | Empty |
| `L` | Lava pool. Fire is safe; Water dies |
| `~` | Water pool. Water is safe; Fire dies |
| `A` | Acid pool. Both die |
| `^` | Fan shaft. Pushes characters up while they're inside it |
| `F` / `W` | Fire / Water spawn point, the cell the character stands in |
| `f` / `w` | Fire / Water exit door, the cell the character stands in. It needs rock below it |
| `r` / `b` | Red gem (Fire only) / blue gem (Water only) |
| `X` | Pushable box (fills the cell) |

Pools replace a floor tile: a character dies by standing on one, not by touching it from the side.

`objects` holds the mechanisms. Objects on the same **channel** (`ch`) are linked together and share a colour in the game.

```json
{ "type": "plate", "at": [x, y], "ch": 1 }
{ "type": "lever", "at": [x, y], "ch": 1, "dir": 1, "toggle": false }
{ "type": "gate",  "at": [x, y], "size": [w, h], "ch": 1, "invert": false }
{ "type": "pulley", "a": [x, y], "b": [x, y], "w": 3, "min": -3, "max": 3 }
```

- **plate**: active while anyone, or a box, is on it.
- **lever**: turns on when someone walks through it in direction `dir` (1 = right, -1 = left) and stays on. With `"toggle": true`, walking through it the other way turns it off again.
- **gate**: solid while its channel is off and open while it's on. `invert` swaps this. A gate never closes on top of a character or a box, so a box pushed into a gateway wedges it open. Vertical gates must be at least 2 tiles tall, because characters are 30px tall.
- **box** (`X` in the rows): one tile, falls under gravity, and is pushed by walking into it (at a slower walk). You can stand on it. A box can't push another box, and boxes can only be pushed, never pulled.
- **pulley**: two platforms `w` tiles wide whose tops start at the top of row `y`. Every character or box resting on a platform (stacked ones included) weighs 1. The heavier side sinks and the other rises at the same speed, carrying whatever is on them; equal weights stay put. `min`/`max` limit side `a` (negative = up, positive = down, in tiles), and side `b` always moves the opposite way. `"travel": n` is short for `min: -n, max: n`. A platform stops rather than crush something or push it into rock.

## The 64 draft levels

There are eight worlds of eight levels each. Each world introduces one idea and the later levels combine them. Levels 33–64 are generated by `tools/gen-levels-33-64.js` from a handful of puzzle templates (bridge, pulley step, counterweight, seesaw, wedge door, ride down) whose solutions are run through the real physics in `test/solutions.test.js`.

| World | Levels | Introduces |
|---|---|---|
| 1. Cinder Caves | 1–8 | Walking, jumping, pools, gems, partner boost (4), split routes (3, 6), first plate (8) |
| 2. Tide Halls | 9–16 | Levers, plates on ledges, holding gates for each other (11), inverted gates (12), several channels (15, 16) |
| 3. Gale Spire | 17–24 | Fans, gates across fan shafts (19, 23), mirrored halves where each player opens the other's gate (22, 24) |
| 4. Twin Core | 25–32 | Everything together: long mirrored climbs, acid runs, plate relays (27), toggle switchbacks (28), the finale (32) |
| 5. Crate Works | 33–40 | Boxes: steps up to high ledges, holding plates down, wedging gates open (36), dropping a box onto a plate (37) |
| 6. Pulley Mill | 41–48 | Pulleys: riding down (41), box-raised bridges you cross one at a time (42), counterweights that lift one player while the other sinks into a lava or water cavern (43, 46), seesaws (45, 47) |
| 7. Counterweights | 49–56 | Boxes and pulleys with switches: wedge then lift (49), levers in the cavern (50), two boxes with two jobs (54), double bridges (55) |
| 8. Grand Machine | 57–64 | Everything, plus fans: riding updrafts out of the works (58, 64), seesaws into a wedge door (63), the finale (64) |

These are **first drafts**. The checker passes all 64, and each pulley's full range is checked with the real physics, but none has been played yet. The difficulty curve, timing and fun all need tuning on real phones.
